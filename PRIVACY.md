# Privacy Policy — Toggle Switch Slicer

*Last updated: November 15, 2026*

Toggle Switch Slicer ("the visual") is a Power BI custom visual published by Felipe Santana.

**Data collection.** The visual does not collect, store, transmit or share any personal data or report data.
It runs entirely inside Power BI and only uses the data that the report author binds to it, to draw the switch
and apply a filter within the same report.

**Network access.** The visual makes no network requests and does not load external scripts, fonts or images.

**Cookies and storage.** The visual does not use cookies, local storage or any other browser storage. Its
settings are saved by Power BI as part of the report.

**Third parties.** No data is shared with the publisher or any third party.

**Contact.** Questions about this policy: open an issue in this repository.

# Política de Privacidade — Chave Seletora (Toggle Switch Slicer)

*Atualizada em: 15/11/2026*

A Chave Seletora ("o visual") é um visual personalizado do Power BI publicado por Felipe Santana.

**Coleta de dados.** O visual não coleta, guarda, transmite nem compartilha dados pessoais ou dados do relatório.
Ele roda inteiramente dentro do Power BI e só usa os dados que o autor do relatório liga a ele, para desenhar a
chave e aplicar um filtro no mesmo relatório.

**Acesso à rede.** O visual não faz requisições de rede e não carrega scripts, fontes ou imagens externas.

**Cookies e armazenamento.** O visual não usa cookies, armazenamento local nem outro armazenamento do navegador.
As configurações são salvas pelo Power BI como parte do relatório.

**Terceiros.** Nenhum dado é compartilhado com o publicador ou com terceiros.

**Contato.** Dúvidas sobre esta política: abra uma issue neste repositório.
